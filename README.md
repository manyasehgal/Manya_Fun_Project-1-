# Fun Project: Model Accuracy Comparison for Guess Game

## Overview
This project combines a playful **Guess the Number** concept with machine learning.  
Synthetic data is generated to represent guesses vs outcomes (too low, too high, correct), and three ML algorithms are trained and compared: **Logistic Regression**, **Decision Tree**, and **K-Nearest Neighbors (KNN)**.  
The goal is to analyze which model best predicts outcomes in this game-like scenario.



##  Contents
- **Data Generation**: Synthetic dataset of guesses (1–100) and outcomes.
- **Models Implemented**:
  - Logistic Regression
  - Decision Tree Classifier
  - K-Nearest Neighbors (KNN)
- **Evaluation**:
  - Accuracy scores
  - Bar chart visualization of model performance



##  Results
- Logistic Regression Accuracy: **0.995**  
- Decision Tree Accuracy: **1.0**  
- KNN Accuracy: **0.995**

##  Analysis
- **Decision Tree** achieved perfect accuracy, handling non-linear boundaries effectively.  
- **Logistic Regression** performed nearly as well, showing strong linear separation.  
- **KNN** matched Logistic Regression but is more sensitive to data distribution.  
- Overall, all three models performed exceptionally well on this simple synthetic dataset.
